# TechBlog Backend

Backend desenvolvido para o desafio técnico da Mind Group.

## Tecnologias

- Node.js
- Express
- TypeScript
- Prisma ORM
- MySQL
- JWT
- Bcrypt
- Multer

## Funcionalidades

- Cadastro de usuários
- Login com JWT
- CRUD de artigos
- Upload de imagem (BLOB)
- Comentários
- Curtidas
- Dashboard

## Como executar

npm install

npm run dev
